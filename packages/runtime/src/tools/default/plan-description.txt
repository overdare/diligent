Create or update a visible checklist for work with meaningful dependencies or multiple substantial outcomes. Skip it for small tasks and ordinary conversation. This tool does not change collaboration mode.

Use actionable steps and keep their status truthful:
- pending: not started; in_progress: active; done: completed; cancelled: removed from the requested scope.
- Keep one active step for sequential work. Reflect completed work before moving on.
- Update the checklist when scope changes. Cancel steps the user defers or abandons; do not mix a new request into an obsolete plan.
- Do not invent follow-up work merely to extend the checklist.
- Before reporting completion, resolve the requested steps. If work is blocked, report the dependency and keep unfinished work distinct from completed or cancelled work.
